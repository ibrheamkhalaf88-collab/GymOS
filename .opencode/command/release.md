description: رفع إصدار digital-pulse (7 ملفات + اختبارات + tag + push + مراقبة CI)
---
نفّذ رفع إصدار لمشروع digital-pulse من جذر المشروع:

1. شغّل: `node scripts/release.mjs $ARGUMENTS`
2. السكربت بيعمل كل شي تلقائياً (تعديل 7 ملفات متسقة + npm test + commit + tag + push بـHTTP/1.1 + مراقبة CI + تحقق من الـAPK بالإصدار) — **لا تعيد أي خطوة يدوياً**
3. إذا فشلت خطوة: **توقف وأبلغني** بالرسالة الحرفية — بدون إصلاحات جانبية بدون إذن
4. ندائي لـ/release = موافقتي على الـpush والـtag — للتجربة الجافة فقط: `node scripts/release.mjs --dry`

بعد النهاية: بلّغني برقم الإصدار، حالة الـCI (أخضر/أحمر + اسم الـworkflow الفاشل إن وجد)، ورابط الإصدار.
