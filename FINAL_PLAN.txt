# 🎯 الخطة النهائية - Digital Pulse Pro (License System)

تاريخ: 2026-08-13
---

## 📋 النظام:

### ✅ **نظام الأكواد:**
- أنت تعمل مجموعة أكواد مسبقة (مثال: DPRO-A1B2C3, DPRO-X7Y8Z9)
- تخزينها في ملف JSON على Netlify
- عند الشراء → ترسل الكود عبر واتساب للزبون

### ✅ **التفعيل:**
- الزبون يفتح الموقع
- يدخل الكود
- الموقع يتحقق من الكود في الـ JSON
- إذا صحيح → يفتح لوحة التحكم
- حفظ الكود محلياً (localStorage)

### ✅ **البيانات:**
- محلية 100% على جهاز المستخدم
- لا تاخد مساحة على السيرفر
- Export/Import للنقل بين الأجهزة

---

## 🗂️ الملفات المطلوبة:

### **1. صفحة التفعيل:**
```
public/license.html
```
- Input: كود التفعيل
- Button: تفعيل
- رسالة: نجح/فشل

### **2. ملف الأكواد (مخفي):**
```
.netlify/functions/licenses.json
أو
public/.well-known/licenses.json (مخفي)
```
- قائمة بالأكواد الصالحة
- مخفي عن الجمهور

### **3. منطق التفعيل:**
```
src/js/license.js
```
- التحقق من الكود
- حفظ محلي
- redirect للوحة التحكم

### **4. Export/Import:**
```
src/js/export.js
```
- Export JSON
- Export Excel (مرتب)
- Import من ملفات
