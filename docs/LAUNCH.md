# 🚀 خطة إطلاق GymOS (ORB Framework)

ORB = **O**wned / **R**ented / **B**orrowed channels + 5 مراحل إطلاق.

## القنوات

### Owned (نملكها — مجانية ودائمة)
- 📱 واتساب بيزنس (+972 568 802 803) — زر "طلب كود" موجود أصلاً بالتطبيق
- 🌐 موقع GitHub Pages الرسمي + الريبو كـ Portfolio
- 💬 حالة واتساب / ستوري أسبوعية: رقم من التطبيق (إيراد الشهر، عدد الأعضاء)

### Rented (مستأجرة — مدفوعة أو مقيدة بقواعد منصة)
- 👥 مجموعات فيسبوك أصحاب الصالات والأندية (فلسطين/الأردن/داخل الخط الأخضر)
- 📌 إعلان ممول $30–50 مستهدف: مهتمين بـ fitness + business، مدن محلية
- 🎥 تيك توك/ريلز: فيديو 60 ثانية "شوفت نظام حجز عربي هيك؟"

### Borrowed (مستعارة — عبر الآخرين)
- 🤝 مورّد أجهزة رياضية محلي: يبيع الحل مع الأجهزة مقابل عمولة
- 🏋️ مدرب معروف يجرب مجاناً ويصور تجربته
- 📣 عملاء الأكواد الأولى → شهادات فيديو قصيرة

## المراحل الخمس

| # | المرحلة | المدة | المهام |
|---|---------|-------|--------|
| 1 | **Pre-launch** | أسبوع | فيديو ديمو 60ث ✅ صفحة أسعار ✅ جهّز 10 أكواد Guest مجانية | اجمع 20 رقم واتساب مهتمين |
| 2 | **Teaser** | 3 أيام | بوست "قريباً — نظام إدارة صالات عربي" + عدّاد تنازلي |
| 3 | **Launch Day** | يوم | رسالة جماعية واتساب للـ 20 رقم + عرض أول 5 صالات ($9 Pro) + انشر الفيديو كل مكان |
| 4 | **Follow-up** | أسبوع | متابعة كل مهتم خلال 24س · عرض سنوي (شهرين مجاناً) · شهادات أول المستخدمين |
| 5 | **Iterate** | مستمر | قياس: كم كود انفعّل؟ مصدر كل عميل؟ ضاعف اللي يشتغل فقط |

## مؤشرات النجاح (أول شهر)

- ≥ 5 أكواد مفعّلة فعلياً
- ≥ 1 صالة تدفع سنوي
- ≤ 3 ساعات زمن رد على طلب جديد

## أدوات جاهزة عندنا بالفعل ✅

- زر واتساب مدمج بشاشة التفعيل (العميل يطلب الكود بنفسه)
- باقة Guest = نسخة تجريبية مثالية للديمو
- لوحة الأكواد تعطيك إحصائيات فورية (متاح/مفعّل اليوم/موقوف)
